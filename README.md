# HerZone
HERZONE — Site web du club universitaire ISET Siliana
======================================================

Le site est un frontend statique composé de :
- index.html : contenu et formulaire de contact
- style.css : styles responsive
- script.js : navigation mobile, validation du téléphone et envoi du formulaire
- assets/herzone-logo.png : logo

Le formulaire envoie les messages à Formspree. Vérifiez dans le tableau de bord
Formspree que le formulaire xkjrkqbr est actif et que son adresse destinataire
est configurée.

Le site peut être déployé sur un hébergement statique. Aucun serveur PHP,
Composer ou identifiant SMTP n'est requis.
